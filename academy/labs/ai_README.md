# AI 应用轨离线实验

在 `academy` 目录使用 Python 3.9 或更新版本运行；只依赖标准库，不调用模型、不连接实验室服务器，也不读取业务数据库。

```bash
python3 labs/ai_retrieval.py
python3 labs/ai_tools.py
python3 labs/ai_training.py
python3 -m unittest discover -s tests -p 'test_ai_labs.py' -v
```

每次只选一个实验。先写预测，再运行；提示与参考解释在对应课程中。

| 实验 | 本次能观察什么 | 不能据此得出的结论 |
|---|---|---|
| `ai_retrieval.py` | 英文词项 TF-IDF 排序、空结果、召回与排名指标 | 中文语义检索、BGE 或真实知识库效果 |
| `ai_tools.py` | 同一请求重放、跨用户拒绝、参数边界 | 跨进程、持久化、并发下的生产幂等保证 |
| `ai_training.py` | 梯度更新、验证选优、测试误差与保存重载 | 大语言模型微调收益或 GPU 性能 |

训练实验使用临时目录保存 JSON，分别在本进程和新 Python 进程重新加载并比较预测，结束自动清理，不覆盖已有权重。模型的均值、尺度和权重一起保存。若需要保存自己的学习产物，请在理解程序后使用自己的实验目录，并记录数据与配置。

测试检查未知查询不误报命中、重复结果不重复计数、越权与请求身份冲突被拒、返回值修改不污染缓存、训练产生改进、重载预测一致以及标准化只拟合训练集。详细执行结果见 `../evidence/ai-checks.json`。

本课代码已执行的记录属于实现证据；学习者需另记录自己对输入、输出、限制及错误的解释，不自动标记已掌握。
