# 共享 GPU 实验的操作约定

文档 ID：d05

资料状态：本项目实验规则

依据与范围：根据已有工作台故障排查和本次资源约束制定；不代表已取得独占资源。

## 设备和预算

本项目计划优先在 GPU 1 运行新推理服务，GPU 0 保留已有基线和按需实验。

两张 32 GB 级别的显卡不会自动变成一张 64 GB 显卡；跨卡运行需要框架和模型配置支持。


## OOM 排查

出现 CUDA out of memory 时，先记录采样时间、输入长度、生成上限、设备和各进程显存占用。

确认自己的重复实例后再正常退出；不能为了腾显存停止其他人的任务。


## 恢复验证

调整输入长度或生成上限后，先执行一次短请求确认恢复，再逐步增加负载。

显存空闲与计算空闲是两个指标，实验前要同时观察。
