# 访问位置与服务端口

文档 ID：d06

资料状态：本项目地址约定与已核对基线

依据与范围：已有端口来源于工作台文档；18300 与 18301 是本项目分配的地址，是否已运行应由健康检查确认。

## 地址含义

127.0.0.1 指向执行请求的那台机器自身；电脑上的回环地址不会自动指向服务器。

在个人电脑访问只监听服务器回环地址的服务时，可以通过 SSH 本地端口转发。


## 端口分工

已有基线模型端口是 18123，已有学习工作台服务器端口是 18200。

本项目给新知识库应用分配端口 18300，给新模型服务分配端口 18301。


## 连接故障

遇到 Connection refused，先在服务所在机器检查监听和健康状态，再检查本机隧道。

Address already in use 表示目标地址或端口已有监听者，应确认进程身份并选择复用或更换自己的端口。
