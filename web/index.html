MEASURE THE SYSTEM

从真实记录理解性能

公开包不包含原始性能报告。自行运行后再保存报告，不能把 Qwen 结果当作混元性能。每份报告先核对模型、日期、精度和请求配置，再解释延迟、吞吐与显存。

LATENCY

首 token 延迟

从提交请求到看到第一个生成片段。客户端与模型内部的计时范围要分开。

THROUGHPUT

吞吐与并发

并发增加可能提高总吞吐，也可能带来排队、失败与单请求变慢。

QUALITY

同一条件再比较

模型、输入、生成参数、实际 token 和服务器负载都会影响结论。

实际实验与验收证据
